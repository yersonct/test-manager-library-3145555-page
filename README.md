# Manager Library Public Website

A static information website, independent of the API and database. It presents the library, its categories, and its community; it does not display or query the operational catalog or member data.

## Run locally

Open `index.html` in a browser or serve this directory with a static web server. To run it as a container alongside the rest of the project, use the sibling `test-manager-library-3145555-infra` Compose configuration.

The "Acceso del equipo" link points to the local operations app at `http://localhost:5173`. Update it only when configuring the site for a specific publishing environment.
